# 🌌🇮🇷 اتوماسیون کانال تلگرام «Daily Science, Space & Reddit»

سیستم کاملاً **رایگان و پایدار** روی GitHub Actions که روزانه دو دسته محتوا را **فقط به فارسی شیرین** در [@daily_sciences](https://t.me/daily_sciences) منتشر می‌کند — با ایموجی و هشتگ‌های مینیمال و حرفه‌ای:

| Workflow | زمان (تهران) | محتوا |
|---|---|---|
| **Reddit Top Daily Post** | هر روز ۱۳:۳۰ (+ پشتیبان ۱۵:۰۰) | ۵ پست برتر r/science+space+astronomy: عنوان فارسی جذاب + خلاصه + عکس + آمار با ارقام فارسی + هشتگ |
| **NASA APOD Daily Post** | هر روز ۲۱:۰۰ (+ پشتیبان ۲۳:۰۰) | عکس/ویدئوی روز ناسا: عنوان فارسی + تاریخ شمسی + اعتبار + توضیح کامل فارسی + هشتگ |

## قالب پست‌ها (فقط فارسی)

**پست ناسا** — کپشنِ عکس/ویدئو:

```
🌌 عکس نجومی روز ناسا

🪐 صندوقچه‌ای گنج در سحابی کارینا

📅 پنجشنبه ۲۶ شهریور ۱۴۰۵
🔭 اعتبار: NASA JPL-Caltech

#نجوم #سحابی_کارینا
```

سپس یک پیام جداگانه با ترجمهٔ کامل و روان توضیحات ناسا.

**پست ردیت**:

```
🦠 واکسیناسیون برای پیشگیری از RSV در نوزادان

مطالعه جدید نشان می‌دهد واکسیناسیون می‌تواند نوزادان را در برابر این ویروس تنفسی محافظت کند.

⬆️ ۱۱٫۹ هزار امتیاز • 💬 ۲۳۴ دیدگاه • r/science

#واکسن #سلامت
```

ایموجیِ ابتدای عنوان و هشتگ‌ها را خودِ هوش مصنوعی متناسب با موضوع هر پست انتخاب می‌کند (مینیمال و هدفمند؛ نام‌های خاص مثل NASA یا r/science به همان شکل می‌مانند).

| Secret | کاربرد |
|---|---|

| `GROK_API_KEY` | کلید هوش مصنوعی برای ترجمه فارسی (تشخیص خودکار سرویس) |

## معماری ترجمه (`llm_translator.py` + `persian_utils.py`)

کلید LLM به‌صورت خودکار تشخیص داده می‌شود: اول **Groq** (api.groq.com) سپس **xAI Grok** (api.x.ai) امتحان می‌شود و اولین سرویس پذیرنده با بهترین مدل موجود استفاده می‌گردد. خروجی ترجمه اعتبارسنجی می‌شود (متن فارسی، طول مناسب، ایموجی معتبر، هشتگ تک‌توکنی) و در صورت ناموفق‌بودن، اجرا **عمداً شکست می‌خورد** تا اجرای پشتیبان دوباره تلاش کند — چون سیاست کانال «فقط فارسی» است و هرگز پست انگلیسی ارسال نمی‌شود.

`persian_utils.py` ابزارهای مشترک فارسی را می‌دهد: تبدیل تاریخ میلادی به **شمسی** (با روز هفته)، **ارقام فارسی** (۱۱٫۹ هزار)، انتخاب ایموجی و اعتبارسنجی هشتگ‌ها.

## معماری داده Reddit (`reddit_top_bot.py`)

ردیت IPهای دیتاسنتر (از جمله GitHub Actions) را در endpoint های عمومی JSON بلاک می‌کند (خطای 403). اسکریپت لایه‌بندی‌شده این‌ها را به‌ترتیب امتحان می‌کند:

1. **JSON عمومی** (www/old/api.reddit.com) — داده زنده، اگر IP بلاک نباشد
2. **OAuth رسمی** — اگر `REDDIT_CLIENT_ID` و `REDDIT_CLIENT_SECRET` تنظیم شده باشند (داده زنده، بدون تأخیر)
3. **آینه Arctic-Shift** (بدون نیاز به ثبت‌نام) — امتیازها حدوداً ۳۰ ساعت بعد از ایجاد پست به‌روز می‌شوند؛ پنجره ۵۴ ساعته + ضدتکرار تضمین می‌کند هر روز ۵ برترینِ واقعیِ منتشرنشده ارسال شود (با حدود یک روز تأخیر)

برای حذف تأخیر و دریافت داده کاملاً زنده: یک «اسکریپت اپ» رایگان در reddit.com/prefs/apps بسازید و دو Secret بالا را اضافه کنید (۲ دقیقه).

## ضدتکرار، سهمیه روزانه و پایداری

- `state.json` (ناسا) تاریخ آخرین APOD ارسال‌شده را نگه می‌دارد؛ `state_reddit.json` (ردیت) ۱۵۰ شناسهٔ آخر + **سهمیهٔ روزانه** (`posts_today`) را — اجرای پشتیبان فقط کسری را که اجرای اصلی نتوانسته تکمیل می‌کند، نه تکرار
- اگر ترجمهٔ فارسی در دسترس نباشد، اجرا شکست می‌خورد و پشتیبان ۲ ساعت بعد دوباره تلاش می‌کند (هرگز پست انگلیسی/دوزبانه ارسال نمی‌شود)
- کامیت روزانه stateها ریپو را همیشه «فعال» نگه می‌دارد (جلوگیری از خاموشی ۶۰روزه GitHub)
- NASA API اگر ورودی امروز را نداشت، آخرین APOD موجود را می‌گیرد؛ عکس‌های بزرگ/پانوراما خودکار فشرده می‌شوند تا همیشه «عکس» ارسال شوند نه «فایل»

## دستورات مفید (Actions → Run workflow)

- **Reddit Top Daily Post**: تیک `dry_run` = عیب‌یابی (دریافت + ترجمه بدون ارسال)، تیک `force` = نادیده‌گرفتن ضدتکرار و سهمیه
- **NASA APOD Daily Post**: تیک `force` = ارسال مجدد همان روز، تیک `dry_run` = پیش‌نمایش ترجمه بدون ارسال

اجرای محلی:

```bash
pip install -r requirements.txt
python reddit_top_bot.py --diag        # عیب‌یابی اتصال LLM + منابع Reddit
python reddit_top_bot.py --dry-run     # پیش‌نمایش بدون ارسال
python nasa_apod_bot.py --dry-run
```

## متغیرهای قابل تنظیم (در فایل workflow)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `SUBREDDITS` | `science+space+astronomy` | سابردیت‌ها (+ جداکننده) |
| `POSTS_COUNT` | `5` | سهمیه پست روزانه ردیت |
| `MIN_SCORE` | `50` | حداقل امتیاز پست ردیت |
| `MIRROR_HOURS` | `54` | پنجره نگاه به عقب آینه (به‌خاطر تأخیر آپدیت امتیاز) |
| `CHANNEL_SIGNATURE` | خالی | امضای پای پست‌ها |
| `SEND_VIDEO_IF_POSSIBLE` | `true` | آپلود فایل ویدئو در روزهای ویدئویی APOD |
